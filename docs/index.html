Miniserve Lite

A minimal static file server written in Python. Serve any directory over HTTP without installing external dependencies.

Get startedView source

01

Overview

  1. 01Python standard library onlyRequires only a Python interpreter. Nothing to install from pip.
  2. 02Windows, Linux, and macOSShell and batch launchers are included for each platform.
  3. 03Minimal setupOne file, one command. No configuration files.
  4. 04Custom portPass a port as the second argument.
  5. 05WASM MIME typeServes .wasm files as application/wasm.
  6. 06MIT licenseUse, modify, and redistribute freely.

02

Installation

Linux / macOS

Run the install script from the repository.

Manual

Clone the repository and work from its directory.

Windows

Use the batch launcher from Command Prompt.

Python

Call the script directly on any platform.

03

Usage

The first argument is the directory to serve. The optional second argument is the port.

Serve the current directory
$ ./miniserve-lite.sh .
Serve a specific directory
$ ./miniserve-lite.sh /path/to/dir
Choose a custom port
$ ./miniserve-lite.sh . 8080

04

Security

The server binds to 0.0.0.0, which can make it reachable from other devices on your network.

  • Only serve directories you intend to share.
  • Keep private files out of the served directory.
  • Avoid running it on untrusted networks.
  • There is no authentication and no HTTPS.
